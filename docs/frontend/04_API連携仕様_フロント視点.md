# OfficeNavi API連携仕様（フロント視点）

## 1. 共通仕様

- Base URL: /api
- Content-Type: application/json
- 日時形式: ISO 8601
- 想定エラーコード: 400, 404, 409, 500

## 2. エラー表示ポリシー

| ステータス | 原因           | UI挙動                                             |
| ---------- | -------------- | -------------------------------------------------- |
| 400        | 入力不正       | 項目エラーまたは画面上部に入力不正メッセージを表示 |
| 404        | 対象データなし | 対象なしメッセージを表示                           |
| 409        | 競合           | 業務競合メッセージを表示し再選択を促す             |
| 500        | サーバーエラー | 汎用エラーメッセージと再試行導線を表示             |

## 3. API別仕様

### 3.1 GET /api/users

- 用途: 社員一覧表示
- 呼び出しタイミング: SCR-001初期表示、SCR-003初期表示
- 成功時:
  - 一覧テーブルに表示
- 失敗時:
  - エラートースト表示

### 3.2 POST /api/users

- 用途: 社員登録
- 呼び出しタイミング: SCR-002登録ボタン押下
- リクエスト:

```json
{
  "name": "山田 太郎",
  "email": "taro.yamada@example.com",
  "password": "Passw0rd!"
}
```

- 成功時:
  - 成功メッセージ表示
  - SCR-001へ遷移し一覧再取得
- 失敗時:
  - 400: バリデーション文言を入力欄へ表示
  - 409: email重複メッセージ表示

### 3.3 GET /api/seats

- 用途: 座席選択肢表示
- 呼び出しタイミング: SCR-003初期表示
- 成功時:
  - プルダウンまたはリストに反映

### 3.4 POST /api/user-seats

- 用途: 着席登録
- 呼び出しタイミング: SCR-003着席ボタン押下
- リクエスト:

```json
{
  "userId": 1,
  "seatId": 10
}
```

- 成功時:
  - 成功メッセージ表示
- 失敗時:
  - 404: ユーザーまたは座席不存在
  - 409: 座席利用中メッセージ表示

### 3.5 POST /api/user-seats/leave

- 用途: 退席登録
- 呼び出しタイミング: SCR-003退席ボタン押下
- リクエスト:

```json
{
  "userId": 1
}
```

- 成功時:
  - 成功メッセージ表示
  - 必要に応じて現在位置表示をクリア

### 3.6 GET /api/users/{userId}/current-seat

- 用途: 現在位置照会
- 呼び出しタイミング: SCR-004照会実行時
- 成功時:
  - ユーザー名、座席名、location表示
- 失敗時:
  - 404: 現在位置なしメッセージ表示

## 4. フロント実装時の注意

- API呼び出し中は送信ボタンを無効化する。
- 同一操作の二重送信防止を共通化する。
- 例外メッセージは生の文字列をそのまま出さず、UI文言にマップして表示する。

## 5. 型定義方針

- APIレスポンスに対応する型を画面単位ではなくAPI単位で定義する。
- 画面内部の表示用型はAPI型から変換して利用する。
